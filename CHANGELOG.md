# Changelog

All notable changes to ORBI Energy Swarm are recorded here.

The project uses Semantic Versioning for repository release metadata. Pre-release
channels remain explicit until their certification gates are satisfied.

## [0.2.0-beta.1] — 2026-09-27

This beta marks the transition from the recovered gameplay baseline into the
premium Web + Android + Infinite Swarm product architecture. It is **not** an RC:
human visual, Infinite play-feel and real-device Android validation remain open.

### Added

- Premium responsive shell, viewport classification, safe-area layout and
  profile-driven HUD/deck composition.
- Touch-first Android controls, formation carousel, lifecycle safety,
  HiDPI backing-store management and quality-tier enforcement.
- Stabilized campaign learning arc, objective guidance, Blackout Devourer
  counterplay guidance and campaign-to-Infinite handoff.
- Infinite Swarm procedural progression from Sector 11 onward with deterministic
  descriptors, mutators, environmental pressure, milestones and boss rematches.
- Evolved enemy variants and bounded live signature mechanics.
- Persistent Infinite records, bounded recent-run archive and Flight Recorder UI.
- Accessibility passes for reduced motion, keyboard focus, semantic combat/modal
  surfaces and reduced flash intensity.
- Tactical audio priority and quality-aware direct VFX budgets.
- Refresh-rate cadence normalization for 60/90/120 Hz behavior.
- Advisory sustained frame-health monitoring.
- Device/orientation × quality certification matrix spanning Android, tablet,
  laptop, desktop and ultrawide classes.
- Canonical GitHub Pages distribution metadata plus an installable PWA shell with
  base-safe manifest, 192/512 install icons and SHA-versioned fail-open caching.
- Reproducible Capacitor 8 Android packaging foundation targeting Android 16 /
  API 36, with local web assets and a CI-built debug APK.
- Deterministic ES-12 RC-readiness evaluation with SHA-bound CI evidence and
  explicit `BLOCKED`, `ELIGIBLE_FOR_PROMOTION`, `RC` and `STABLE` decisions.

### Changed

- Repository quality gates now protect smoke tests, TypeScript correctness,
  release-contract consistency, production builds and RC-readiness evidence.
- Presentation and performance systems are increasingly contract-driven while
  preserving the original gameplay baseline.
- Distribution remains PWA-first for the beta; native Android packaging is now
  reproducible, while release signing remains external and deferred until the
  manual real-device certification obligations are complete.

### Known certification blockers

- Issue #4: human visual/responsive certification.
- Issue #5: manual Infinite difficulty/play-feel validation.
- ES-11 hardware validation: thermal, battery, browser chrome, hand/thumb
  ergonomics and OEM GPU/driver behavior on real devices.
- RC promotion remains blocked until the manual evidence above is complete;
  Android release signing also remains external to the repository.

## [0.1.0] — Recovery baseline

Frozen prototype-recovery baseline used to preserve the original gameplay DNA
before premium/responsive/Infinite product development.
